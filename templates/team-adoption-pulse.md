# Team Adoption Pulse

Use this as a quick conversation or short form before a first session. It is not a skills test and it is not performance monitoring.

## The Questions

Ask each person to choose the answer that feels closest.

| Question | Options |
| --- | --- |
| How often do you use an approved AI tool in normal work? | Never / Once or twice / Some weeks / Most weeks |
| What would you most like help with? | Preparing / Writing / Organising notes / Researching / Reviewing / Something else |
| What makes you hesitate? | I do not know where to start / I am unsure what is safe / I do not trust the output / I do not have time / I do not see the point |
| Which output would be most useful? | First draft / Questions to ask / Summary / Options to review / Clearer structure |
| What do you already check before using an AI output? | Facts / Tone / Assumptions / Nothing yet / Other |
| Would you try one small test over the next two weeks? | Yes / Maybe / Not right now |

## What To Do With The Answers

Look for patterns, not rankings. For example:

- if people are unsure what is safe, begin with the boundary;
- if people do not know where to start, choose one familiar job together;
- if people distrust the output, practise the human check rather than trying to persuade them;
- if people want different things, run a small volunteer experiment rather than forcing one use case on everyone.

Do not publish individual answers. Share only the themes the group agrees are useful.
