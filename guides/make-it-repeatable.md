# Make It Repeatable

If a prompt worked once, do not just save the final text in a random note. Capture what made it work.

## Keep Five Things

| Keep | Why it matters |
| --- | --- |
| The job | A clear task stops the prompt becoming a general chat |
| The input | Good output depends on what information was available |
| The output shape | A repeatable format makes checking faster |
| The checks | They stop confident mistakes becoming customer messages |
| The boundary | They clarify what a person must still decide or do |

## Turn a Prompt Into a Team Asset

Write it in plain English so someone else can adapt it:

- What this helps with
- What to provide
- What it will produce
- What to check
- What never happens automatically

Do not call it a best practice until another person has used it and found it helpful. A good private prompt is a starting point, not a company process.
