# Make It Repeatable

If a prompt worked once, don't just save the final text in a random note. Write down what made it work.

## Keep Five Things

| Keep | Why it matters |
| --- | --- |
| The job | A clear task stops the prompt turning into a general chat |
| The input | Good output depends on what information it had |
| The output shape | A format you repeat is quicker to check |
| The checks | They stop confident mistakes turning into customer messages |
| The boundary | It shows what a person must still decide or do |

## Turn a Prompt Into a Team Asset

Write it in plain English so someone else can adapt it:

- What this helps with
- What to provide
- What it will produce
- What to check
- What never happens automatically

Don't call it best practice until another person has used it and found it helpful. A good private prompt is a starting point, not a company process.
