# Improve a First Prompt

A weak first prompt is normal. Treat it as a draft of a working method, not proof that AI is useless or that someone is bad at using it.

## Find the Missing Piece

| If the output... | Usually improve... |
| --- | --- |
| Sounds generic | The job and the context |
| Invents detail | The instruction about facts, assumptions and unknowns |
| Is too long | The output format and length |
| Misses the point | The example of a useful result |
| Is hard to trust | The checking step |
| Needs too much editing | The quality of the input |

## Use the Four Part Rewrite

Ask the person to rewrite the prompt in four parts:

1. **The job**
   “Turn these approved call notes into a short follow up draft.”

2. **The input**
   “Use only the notes below. Treat anything missing as unknown.”

3. **The output**
   “Give me a three point summary, action list and email draft.”

4. **The check**
   “Do not invent commitment, urgency, budget or customer intent. I will check every line before sending.”

## Compare, Do Not Guess

Run the old version and the new version against the same safe sample. Ask which is easier to check and more useful for the real job.

The improved prompt does not become a team asset yet. Record it in the [Team Learning Log](../templates/team-learning-log.md) and see whether another person can adapt it.
