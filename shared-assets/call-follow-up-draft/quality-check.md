# Call Follow Up Quality Check

Use this before sending any draft created with the method.

| Check | Ask yourself |
| --- | --- |
| Facts | Is every statement supported by the call notes? |
| Agreement | Does it describe only what was actually agreed? |
| Actions | Are action owners and dates correct, or clearly still open? |
| Assumptions | Did the draft make an uncertainty sound certain? |
| Tone | Does this sound like me and fit the customer relationship? |
| Value | Does it make the next step clearer for the customer? |
| Boundary | Am I the person deciding whether to send it? |

If any answer is no or unclear, edit the draft or go back to the notes. Do not treat a fluent email as proof that it is correct.

## Common Mistakes

- Turning interest into commitment.
- Adding a date that was only suggested.
- Making rough notes sound like confirmed facts.
- Writing a longer email than the customer needs.
- Leaving in the AI's generic wording instead of making it sound like a person.
