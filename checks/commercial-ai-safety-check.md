# Commercial AI Safety Check

Use this before you share something AI helped produce, or turn it into a repeatable team method.

| Check | Ask |
| --- | --- |
| Tool | Is this an approved tool for this information? |
| Input | Does the input leave out the customer, employer and confidential material that should stay out? |
| Facts | Can every factual claim be traced to a reliable source? |
| Assumptions | Can you still see where it's uncertain and where it's judgement? |
| Tone | Would this sound sensible coming from a person on the team? |
| Action | Is a person still approving messages, commitments and system changes? |
| Learning | Did the team record what was useful and what needed correction? |

If any answer is no or unclear, stop and fix the input or process before using the output.
